4. TIMELINE AND PREVIEW FLOW
======================================================================

  TimelineModel is the only owner of the active multi-track model:
    -> dynamic V1/V2/V3..., A1/A2/A3..., T1/T2...
    -> independent timelineStart, duration and sourceStart
    -> transforms, opacity, position, scale, rotation and blend mode
    -> effects, transitions and keyframes
    -> linked source audio and independently detached audio

  TimelineController
    -> full edited duration, playhead and zoom
    -> track creation, split and delete commands

  TimelineSelectionController
    -> single, Ctrl-toggle, range and marquee selection state

  TimelineEditor
    -> cross-track moves
    -> snap to playhead, markers and clip edges
    -> split, resize, insert and delete
    -> lock checks and linked-audio synchronization
    -> effect, transition, transform and keyframe editing

  DynamicTimelineView
    -> blue committed playhead and separate green skimmer
    -> click/drag seeking
    -> filmstrip rendering and real source waveform rendering
    -> linked audio inside video; detached audio on audio tracks
    -> caption blocks and text tracks
    -> visibility, mute, lock and delete controls
    -> Ctrl/Shift/marquee multi-selection

  Program Monitor
    -> resolves active clips at the complete timeline playhead
    -> stacks video layers by z-index
    -> adds text, captions and watermark overlays
    -> transport shows current and complete edited duration

======================================================================
5. EXPORT, CAPCUT, CAPTIONS AND AUTOMATION
======================================================================

  ExportCoordinator + RenderTaskQueue
    -> queue single, sequence and multi-track exports
    -> sequential execution with pause/resume boundary

  MultiTrackFilterBuilder
    -> trim/setpts/delay each source
    -> overlay video tracks in z-order
    -> mix synchronized audio tracks

  AudioMixerService
    -> atrim, asetpts, volume/mute, fade, adelay and amix

  Caption service
    -> Faster-Whisper process and transcript cache
    -> cue timing and ASS generation
    -> CUDA attempt with CPU fallback

  CapCut service
    -> CapCut draft JSON and safe media paths
    -> protected root metadata registration

  Automation
    -> --automation-job JSON
    -> localhost MCP bridge
